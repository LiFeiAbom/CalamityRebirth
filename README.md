# 灾厄重生 / Calamity Rebirth

将旧版灾厄中具有代表性的内容重新带回现代 tModLoader，并分别适配现代灾厄、经典 1.4.2.101 与 CalRD 1.4.5.7。

本模组不是旧版灾厄的完整复刻，而是按已实现内容逐步扩展的个人爱好项目。部分属性、价格、稀有度、配方与视觉效果经过重新平衡或兼容调整。

当前版本：`0.1.2.4`

## 当前内容

- 五职业高级饰品链：战士、远程、法师、召唤与盗贼。
- 血神核心系列：血神核心、血炎晶核、血契、血肉图腾、血腥蠕虫围巾与血腥蠕虫牙。
- 元素之握、代达罗斯纹章、元素箭袋、空灵护符与斯塔提斯召唤链。
- 盗贼镜片潜行链、纳米技术与晶光头骨。
- 鸿蒙方舟完整武器链与对应自定义弹幕。
- 禅心剑、灼辉金源之翼及多套自定义稀有度。
- 增益药水、酒类、永久饰品栏解锁与可选经典灾厄削弱回调。

完整内容与数值请以模组内物品说明和创意工坊页面为准。

## 兼容环境

本模组使用软依赖，支持以下灾厄分支：

| 内部模组名 | 版本 |
| --- | --- |
| `CalamityMod` | 现代 2.2.2 |
| `CalamityModClassicPreTrailer` | 经典 1.4.2.101 |
| `CalRD` | 经典 1.4.5.7 |

建议一次只启用一个灾厄分支。未启用受支持分支时，基础物品仍可加载，但部分配方、职业属性和高级兼容功能不可用。

## 构建

将仓库放在 tModLoader 的 `ModSources/CalamityRebirth` 目录中，然后在仓库根目录运行：

```powershell
dotnet build CalamityRebirth.csproj
```

也可以直接在 Visual Studio 2022 中打开 `CalamityRebirth.sln` 并生成项目。

构建前请确保同级 `ModSources` 目录中存在对应的 `tModLoader.targets`，并安装项目使用的 tModLoader 版本。

## 仓库结构

| 路径 | 内容 |
| --- | --- |
| `Content/Items` | 饰品、武器、药水与材料 |
| `Content/Projectiles` | 自定义弹幕与命中逻辑 |
| `Content/ModBuffs` | 增益和减益 |
| `Content/Rarities` | 自定义稀有度 |
| `Players` | 玩家属性、输入与多人同步 |
| `Systems` | 配置、回调与系统逻辑 |
| `Utilities` | 灾厄版本兼容和通用工具 |
| `Localization` | 中文与英文本地化 |
